# Snowflake Certification Enablement Platform

The Snowflake Certification Enablement Platform manages an employee's certification journey from nomination through enrollment, learning-plan generation, progress tracking and certification readiness.

## Current Native App Scope

The first implementation focuses on:

- Identifying the signed-in Snowflake user
- Displaying the user's name and organisational role
- Showing the actions permitted for that user
- Supporting employee self-nomination
- Supporting Pod Lead nomination of eligible members from their own Pod
- Routing regular employee self-nominations to their Pod Lead
- Routing Pod Lead self-nominations to the Studio Lead
- Supporting Studio Lead approval only when required

## Current Status

This is an initial Native App implementation. The first milestone contains the application shell, home page and user-identity foundation.
